1. Current API Endpoints

All AJAX API endpoints reside in the Webpage/api/ directory and communicate using application/json.

Endpoint Path	HTTP Method	Input Content-Type	Purpose
api/check_duplicate.php	GET / POST	Query / Form-Data	Real-time validation for team names, roll numbers, emails, and phone numbers.
api/save_team_step.php	POST	application/json	Step 1: Saves team identity, student members (lead + co-leads), and 2–3 mentors.
api/save_idea_step.php	POST	application/json	Step 2: Saves project title, problem statement, existing vs. proposed solutions, and PoC type.
api/save_readiness_step.php	POST	application/json	Step 3: Saves current TRL level (1–4), prior work done, external funding history, and IP status.
api/save_poc_plan_step.php	POST	application/json	Step 4: Saves technical feasibility deliverables, test methodology, success criteria, and 6-month roadmap milestones.
api/save_budget_step.php	POST	application/json	Step 5: Saves itemized cost breakdown (up to ₹1,00,000 maximum) with technical justifications.
api/save_market_step.php	POST	application/json	Step 6: Saves target customers, market size/need, commercialisation route, and measurable societal impact.
api/save_declaration_step.php	POST	application/json	Step 7: Records Team Lead digital e-signature (Name DD/MM/YYYY), 5 declarations, and sends review links to mentors.
api/resend_mentor_email.php	POST	application/json	Regenerates or resends unique magic authorization approval links to mentors.
api/save_mentor_approval.php	POST	application/json	Processes Faculty & Industry mentor approval / decline decision, consent clauses, and digital e-signature.
api/subscribe.php	POST	Form-Data	Records student interest and launch alert subscriptions into registration_alerts.

2. SQL Database Tables & Columns
Database Name: itech_seed_2027
Engine: InnoDB (MySQL 8.0 / MariaDB 10.4)
Default Charset: utf8mb4 with utf8mb4_unicode_ci
Table 1: teams

Tracks overall team registration standing, unique application number, and current step progress.

Column	Type	Nullable	Key / Extra	Default	Description
id	int(11)	NO	PRI (auto_increment)	None	Internal primary key.

team_name	varchar(150)	NO	UNI	None	Unique team title.

has_woman_member	tinyint(1)	NO		0	Diversity criterion flag (1 or 0).

status	enum(...)	YES		'Draft'	'Draft', 'Submitted', 'Under Screening', 'Shortlisted', 'Pitch Day', 'Sanctioned', 'Rejected'.
created_at	timestamp	NO		current_timestamp()	Creation timestamp.
updated_at	timestamp	NO		current_timestamp()	Auto-updated timestamp.
